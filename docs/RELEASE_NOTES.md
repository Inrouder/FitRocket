# FitRocket v0.14.3 – Updates bequem direkt in der App

Unter **Profil → In-App-Update prüfen** lädt FitRocket die aktuelle APK künftig selbst aus dem offiziellen GitHub Release herunter, zeigt den Fortschritt und startet anschließend den Android-Installationsdialog. Du musst die APK nicht mehr manuell im Browser herunterladen oder in den Dateien suchen.

Vor dem Installieren vergleicht FitRocket die neue APK mit der bereits installierten App: Paketname, höhere Version und identische Android-Signatur sind vorgeschrieben. Unbekannte Downloadquellen und abweichende Signaturen werden abgelehnt.

Android benötigt bei privaten APK-Updates normalerweise weiterhin deine Bestätigung im Systemdialog. Möglicherweise musst du einmalig die Berechtigung „Aus dieser Quelle zulassen“ für FitRocket aktivieren. Diese Sicherheitsabfragen werden nicht umgangen.

Alle bisherigen FitRocket-Funktionen und lokalen Daten bleiben bei einem regulären signierten Update erhalten.
