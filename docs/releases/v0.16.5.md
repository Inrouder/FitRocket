# FitRocket v0.16.5 – Eigene Kochbuchrezepte löschen

- Eigene und mit KI gespeicherte Rezepte können im Kochbuch durch Wischen nach links entfernt werden.
- Eine Sicherheitsabfrage verhindert versehentliches Löschen.
- Mitgelieferte Rezepte bleiben geschützt und lassen sich weiterhin nur ausblenden.
- Bereits im Tagebuch gebuchte Mahlzeiten bleiben unverändert.

Die Löschung entfernt das gespeicherte Rezept einschließlich seines zugeordneten Fotos aus der lokalen Kochbuchliste. Bitte vorher ein Backup anlegen, falls du es später noch benötigst.
