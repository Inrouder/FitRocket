# FitRocket v0.16.11 – Spontanes Lebensmittel schnell eintragen

- Neuer Schnellzugriff **„Spontanes Lebensmittel“** im Tagebuch unter „Schnell hinzufügen“.
- Name eines Gerichts oder Lebensmittels, Punkte **pro Portion** und Anzahl der Portionen direkt eintragen.
- Gesamtpunkte werden vor dem Speichern sofort angezeigt: beispielsweise 5,5 Punkte × 4 Portionen = 22 Punkte.
- Auch Teilportionen wie 0,5 oder 1,5 werden unterstützt.
- Die gewünschte Tageszeit kann ausgewählt werden; gebucht wird auf das aktuell gewählte Tagebuchdatum.
- Die Buchung wird nur im Tagebuch gespeichert und nicht als neues Lebensmittel in den Katalog eingetragen. Bestehende ZeroPoints bleiben unverändert.
- Gespeicherte Buchungen werden vom regulären FitRocket-Backup erfasst.
